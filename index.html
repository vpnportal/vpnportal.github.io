Install ပြီးရင်

  1. Login ဝင်ပါရှိပြီးသား Google သို့မဟုတ် Apple အကောင့်နဲ့ တစ်ချက်နှိပ်ပြီး အကောင့်ဖွင့်ပါ။
  2. VPN ကို ခွင့်ပြုပါVPN Portal က VPN ထည့်ခွင့် ဖုန်းက တစ်ခါ မေးပါမယ်။ Allow ကို နှိပ်ပါ။
  3. START ကို နှိပ်ပါAuto မှာထားပါ သို့မဟုတ် ဆာဗာ ရွေးပါ။ Android မှာ VPN မပိတ်သွားအောင် Background ခွင့်ပြုချက်ကိုပါ App က ကူညီပေးပါတယ်။
